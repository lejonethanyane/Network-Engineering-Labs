
# Project 01 — Network Implementation Evidence

This folder contains screenshots and technical evidence collected during the Cisco Packet Tracer implementation of the Northstar Business Solutions network.

Evidence will include:

- Network topology
- VLAN and switchport configuration
- 802.1Q trunk verification
- STP verification
- Inter-VLAN routing and SVI verification
- HSRP gateway redundancy and failover
- ACL security configuration and testing
- Troubleshooting and post-change verification

All evidence relates to a simulated lab environment.
